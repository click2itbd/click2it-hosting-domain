# 📁 Click2IT Domain & Hosting Platform — File Structure Documentation

এই ডকুমেন্টে প্রজেক্টের প্রতিটি ফোল্ডার এবং ফাইলের নাম, তাদের কাজ এবং ভবিষ্যতে মেইনটেইন বা ফিচার আপডেট করার জন্য কোন ফাইল কেন প্রয়োজন তা বিস্তারিতভাবে লেখা আছে।

---

## ১. রুট ফোল্ডার (Root Directory Files)

| ফাইলের নাম                      | কাজ (What it does)                                                                             | কেন দরকার (Why it is needed)                                                |
| :------------------------------ | :--------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------- |
| `package.json`                  | ফ্রন্টএন্ড ও ডেভেলপমেন্টের সকল প্যাকেজ এবং স্ক্রিপ্ট (`dev`, `build`, `lint`) ধারণ করে।        | প্রজেক্ট রান, বিল্ড এবং ডিপেন্ডেন্সি ম্যানেজ করার জন্য অপরিহার্য।           |
| `server.ts` & `server.js`       | ইউনিফাইড সার্ভার যা ফ্রন্টএন্ড এবং ব্যাকএন্ড API একই পোর্টে (`PORT=3000`) চালু করে (`server.js` cPanel Node.js এন্ট্রি পয়েন্ট)। | একটি কমান্ডে (`npm run dev` বা প্রোডাকশনে) পুরো অ্যাপ্লিকেশন চালানোর জন্য।  |
| `index.html`                    | ওয়েবসাইটের মূল HTML এন্ট্রি পয়েন্ট, এসইও মেটা ট্যাগ ও ফন্ট লোডার।                              | ব্রাউজারে React অ্যাপ লোড করা এবং ডিফল্ট SEO/OpenGraph টাইটেল দেখানোর জন্য। |
| `vite.config.ts`                | Vite বান্ডেলার এবং Tailwind CSS কনফিগারেশন।                                                    | ফ্রন্টএন্ড কোড দ্রুত বিল্ড (`dist/` ফোল্ডার তৈরি) ও অপ্টিমাইজ করার জন্য।    |
| `tsconfig.json`                 | TypeScript কম্পাইলার সেটিংস।                                                                   | কোডে টাইপ চেকিং এবং এরর ধরার জন্য।                                          |
| `.env` / `.env.example`         | সিক্রেট কী ও এনভায়রনমেন্ট ভেরিয়েবলের তালিকা (WHM, Openprovider, Firebase, SMTP)।               | সার্ভার ও API ক্রেডেনশিয়াল নিরাপদে সংরক্ষণের জন্য।                          |
| `firebase.json` & `.firebaserc` | Firebase Hosting, Functions ও Firestore কনফিগারেশন।                                            | Firebase-এ রুলস বা ফাংশন ডেপ্লয় করার জন্য।                                  |
| `firestore.rules`               | Firestore ডাটাবেজের সিকিউরিটি রুলস।                                                            | ডাটাবেজ রিড/রাইট পারমিশন নিয়ন্ত্রণের জন্য।                                  |
| `upload.php`                    | cPanel সার্ভারে ইমেজ আপলোড করার PHP স্ক্রিপ্ট।                                                 | কাস্টম ছবি বা ফাইল সরাসরি হোস্টিং সার্ভারে আপলোড করার জন্য।                 |
| `.cpanel.yml`, `deploy.sh`, `.htaccess` & `CPANEL_GIT_DEPLOYMENT_GUIDE.md` | cPanel ও সার্ভারে অটোমেটিক ডেপ্লয়মেন্ট স্ক্রিপ্ট, রাউটিং রুলস ও ডেপ্লয়মেন্ট গাইড। | গিট থেকে সরাসরি লাইভ cPanel সার্ভারে কোড আপডেট ও হোস্ট করার জন্য।          |

## ২. ফ্রন্টএন্ড কোর ফাইল (`src/`)

| ফাইলের নাম        | কাজ (What it does)                                                                                               | কেন দরকার (Why it is needed)                               |
| :---------------- | :--------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------- |
| `src/main.tsx`    | React অ্যাপ্লিকেশনের মূল স্টার্টিং ফাইল যা `App.tsx`-কে `index.html`-এ মাউন্ট করে।                               | ফ্রন্টএন্ড চালু করার মূল এন্ট্রি পয়েন্ট।                   |
| `src/App.tsx`     | পুরো সাইটের সকল রাউটিং (`/`, `/domain`, `/vps`, `/admin`, `/profile` ইত্যাদি) নিয়ন্ত্রণ করে।                     | কোন লিংকে গেলে কোন পেজ ওপেন হবে তা নির্ধারণ করার জন্য।     |
| `src/firebase.ts` | ফ্রন্টএন্ডের সাথে Firebase Auth, Firestore এবং Storage-এর সংযোগ স্থাপন করে।                                      | ইউজার লগইন এবং রিয়েল-টাইম ডাটাবেজ রিড/রাইট করার জন্য।     |
| `src/types.ts`    | পুরো প্রজেক্টের TypeScript ডাটা মডেল ও ইন্টারফেস (`HostingPlan`, `HostingOrder`, `DomainOrder`, `SiteSettings`)। | কোডের ডাটা স্ট্রাকচার ঠিক রাখা এবং বাগ প্রতিরোধ করার জন্য। |
| `src/index.css`   | গ্লোবাল স্টাইল এবং Tailwind CSS ইমপোর্ট।                                                                         | সাইটের ডিজাইন ও রেসপনসিভ লেআউটের জন্য।                     |

## ৩. গ্লোবাল কন্টেক্সট ও স্টেট (`src/context/`)

| ফাইলের নাম            | কাজ (What it does)                                                                                      | কেন দরকার (Why it is needed)                                                 |
| :-------------------- | :------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------- |
| `AuthContext.tsx`     | বর্তমানে লগইন থাকা ইউজার এবং সে Admin কি না (`isAdmin`, `canAccessAdmin`) তা ট্র্যাক করে।               | প্রাইভেট পেজ ও অ্যাডমিন প্যানেল সুরক্ষিত রাখার জন্য।                         |
| `CartContext.tsx`     | ডোমেইন ও হোস্টিং কার্টে যোগ করা আইটেম, প্রোমো ডিসকাউন্ট ও টোটাল হিসাব রাখে।                             | কাস্টমার ডোমেইন/হোস্টিং সিলেক্ট করে চেকআউট পর্যন্ত নেওয়ার জন্য।              |
| `SettingsContext.tsx` | Firestore-এর `settings/site` থেকে ব্র্যান্ড নাম, লোগো, ফোন, ইমেইল ও পেমেন্ট নম্বর রিয়েল-টাইমে লোড করে। | অ্যাডমিন থেকে ফোন/ইমেইল/লোগো বদলালে সাথে সাথে পুরো সাইটে আপডেট দেখানোর জন্য। |
| `ConfirmContext.tsx`  | যেকোনো গুরুত্বপূর্ণ অ্যাকশনের আগে কনফার্মেশন মডাল (Yes/No পপআপ) দেখায়।                                  | ভুলবশত ডিলিট বা ক্যান্সেল হওয়া ঠেকানোর জন্য।                                 |

## ৪. ফ্রন্টএন্ড সার্ভিস ও এপিআই কানেক্টর (`src/services/`)

| ফাইলের নাম              | কাজ (What it does)                                                                               | কেন দরকার (Why it is needed)                                      |
| :---------------------- | :----------------------------------------------------------------------------------------------- | :---------------------------------------------------------------- |
| `apiClient.ts`          | ব্যাকএন্ড সার্ভারের সাথে যোগাযোগের মূল HTTP ক্লায়েন্ট (Firebase Auth Token সহ রিকোয়েস্ট পাঠায়)। | নিরাপদে ব্যাকএন্ড API কল (`GET`, `POST`) করার জন্য।               |
| `domainApi.ts`          | ডোমেইন সার্চ, প্রাইসিং, হুয়েইজ (WHOIS), নেমসার্ভার ও রিনিউ API কল হ্যান্ডেল করে।                 | ডোমেইন সংক্রান্ত সকল ফ্রন্টএন্ড ফিচার সচল রাখার জন্য।             |
| `hostingApi.ts`         | হোস্টিং অ্যাকাউন্ট তৈরি, সাসপেন্ড, আনসাসপেন্ড ও প্যাকেজ আপগ্রেড API কল করে।                      | cPanel/WHM সার্ভারের সাথে ফ্রন্টএন্ডের সংযোগের জন্য।              |
| `cloudLinuxApi.ts`      | CloudLinux লাইসেন্স স্ট্যাটাস ও অ্যাক্টিভেশন API কল করে।                                         | লাইসেন্স সার্ভিস পেজ ও অটোমেশনের জন্য।                            |
| `paymentApi.ts`         | bKash, Nagad এবং SSLCommerz পেমেন্ট গেটওয়ে সেশন তৈরি করে।                                       | অনলাইন পেমেন্ট গ্রহণের জন্য।                                      |
| `emailService.ts`       | অর্ডার কনফার্মেশন, সার্ভিস অ্যাক্টিভেশন ও ইনভয়েস ইমেইল পাঠায় এবং ইমেইল লগ রাখে।                  | কাস্টমারকে অটোমেটিক ইমেইল নোটিফিকেশন পাঠানোর জন্য।                |
| `packageCostEngine.ts`  | কাস্টম হোস্টিং প্যাকেজের রিসোর্স (CPU, RAM, NVMe, Bandwidth) অনুযায়ী খরচ ও বিক্রয়মূল্য হিসাব করে।| কাস্টম প্যাকেজ বিল্ডার ও ডায়নামিক প্রাইসিং ক্যালকুলেশনের জন্য।     |

| `src/lib/imageCompressor.ts`       | প্রোফাইল ছবি বা ডকুমেন্ট আপলোডের আগে সাইজ কমিয়ে অপ্টিমাইজ করে।           | ফাস্ট আপলোড ও স্টোরেজ বাঁচানোর জন্য।                    |
| `src/lib/logoBase64.ts`            | পিডিএফ ইনভয়েসের ভেতর ব্যবহারের জন্য কোম্পানির লোগো Base64 ফরম্যাটে রাখে। | অফলাইনেও যেন পিডিএফ ইনভয়েসে লোগো নিখুঁতভাবে রেন্ডার হয়। |
| `src/hooks/useDomainSearch.ts`     | ডোমেইন সার্চ করার লজিক ও লোডিং স্টেট হ্যান্ডেল করে।                      | বিভিন্ন পেজে ডোমেইন সার্চ বার সহজে ব্যবহারের জন্য।      |
| `src/hooks/useHostingApiConfig.ts` | হোস্টিং API কনফিগারেশন লোড ও সেভ করার হুক।                               | অ্যাডমিন API সেটিংস পেজের জন্য।                         |
| `src/hooks/useSiteContext.ts`      | সাইটের বর্তমান কন্টেক্সট (`hosting`) নির্ধারণ করে।                       | লেআউট ও নেভিগেশনের সামঞ্জস্যতার জন্য।                   |

## ৬. পাবলিক ও ক্লায়েন্ট পেজসমূহ (`src/pages/`)

### মূল পেজ (`src/pages/`)

| ফাইলের নাম                                                          | কাজ (What it does)                                                                                  | কেন দরকার (Why it is needed)                                            |
| :------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------- |
| `Hosting.jsx`                                                       | ওয়েবসাইটের মূল হোমপেজ (`/` এবং `/hosting`)।                                                         | ভিজিটর সাইটে ঢুকলে প্রথমেই হোস্টিং ও ডোমেইন অফার দেখানোর জন্য।          |
| `HostingDetails.tsx`                                                | নির্দিষ্ট কোনো হোস্টিং ক্যাটাগরির (`/hosting/:serviceId`) বিস্তারিত প্যাকেজ দেখায়।                  | ক্যাটাগরি অনুযায়ী আলাদা প্ল্যান ও ফিচার তুলনা করার জন্য।                |
| `Login.tsx`                                                         | ইউজার লগইন, রেজিস্ট্রেশন ও পাসওয়ার্ড রিসেট পেজ (`/login`)।                                          | কাস্টমার ও অ্যাডমিন অ্যাকাউন্টে প্রবেশের জন্য।                          |
| `Profile.tsx`                                                       | ক্লায়েন্ট এরিয়া ড্যাশবোর্ড (`/profile`) — প্রোফাইল, ওয়ালেট, অর্ডার, সার্ভিস, টিকিট ও ডোমেইন অফার। | কাস্টমার যেন তার কেনা সকল ডোমেইন, হোস্টিং ও বিল নিজে ম্যানেজ করতে পারে। |
| `MyServices.tsx`                                                    | কাস্টমারের অ্যাক্টিভ হোস্টিং ও ডোমেইন সার্ভিস ম্যানেজমেন্ট পেজ (`/account/services`)।               | cPanel লগইন, নেমসার্ভার পরিবর্তন ও সার্ভিস আপগ্রেড করার জন্য।           |
| `PaymentSimulation.tsx`, `PaymentCallback.tsx`, `PaymentReturn.tsx` | পেমেন্ট গেটওয়ে থেকে পেমেন্ট সম্পন্ন বা ক্যান্সেল হয়ে ফিরে আসার পেজ।                                | পেমেন্ট স্ট্যাটাস ভেরিফাই করে অর্ডার কনফার্ম করার জন্য।                 |

## ১০. সংক্ষেপে: ভবিষ্যতে কোথায় হাত দেবেন? (Quick Cheat Sheet)

1. **হোমপেজের ডিজাইন বা সেকশন পরিবর্তন করতে চাইলে:** `src/pages/Hosting.jsx` এবং `src/pages/hosting-sections/` ফোল্ডারে।
2. **মেনুবার বা ফুটারের লিংক পরিবর্তন করতে চাইলে:** `src/components/navbars/HostingNavbar.tsx` এবং `src/components/Footer.tsx` ফাইলে।
3. **নতুন কোনো পেজ বা রাউট যোগ করতে চাইলে:** `src/pages/hosting/`-এ ফাইল বানিয়ে `src/App.tsx`-এ রাউট যুক্ত করবেন।
4. **ডোমেইন বা cPanel অটো-প্রভিশনিং লজিক পরিবর্তন করতে চাইলে:** `backend/src/services/fulfillment.ts` এবং `backend/src/providers/` ফোল্ডারে।
5. **অ্যাডমিন প্যানেলের কোনো ট্যাব বা ফিচার পরিবর্তন করতে চাইলে:** `src/pages/hosting-dashboard/` ফোল্ডারে।
